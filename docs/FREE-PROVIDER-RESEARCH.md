# Free cloud routing research — 14 October 2026

Free routing software does not allocate provider tokens. Failover needs an authorized account/model with remaining quota and an allowed endpoint. Penguin also currently caps direct inference at two attempts per role; that bound is an application choice, not a promise from upstream FreeRide. All attempts use shared accounting. Unknown outcomes are never automatically resent.

The directories' provider figures are community claims, not verified live entitlements. Official endpoint documentation/account access could not be verified for new providers in this environment. No new provider account was connected, no paid route enabled, no public chat site scraped and no additional model hosted locally. Free-LLM/9Router must not be treated as sources of credits themselves.

“7B” in a model name normally describes approximately seven billion model parameters. It is distinct from a token allowance. A quoted service token pool may also be aggregate usage across accounts/time, not a personal allocation. No inspected project established a guaranteed seven-billion-token free allowance for this application.

For the current two-provider deployment, quota-aware bounded waits and model selection help when another route is eligible. Provider quotas/privacy restrictions remain authoritative. Additional independent providers can expand available capacity only after their current free plan, permitted automated use, credentials and billing gates are verified. All-unavailable periods must queue/pause research rather than invent an answer or silently switch to a paid provider.
